# Changelog

## 0.2.0 (2026-11-03)

- New look on SJ Utility UI (shared with Clickloom, FolderPilot and Netlume): side navigation with your layouts, Mica on Windows 11, light and dark themes, Fluent icons, messages in the window instead of pop-ups, new app icon.
- Polish and English everywhere: window, tray menu, messages and errors. Follows the Windows display language; switch it in Settings, the choice is kept.
- Settings in three groups (General, PaneKeeper, Advanced) with language, theme and a button that opens the data folder. New About page with version and project links.
- Deleting a layout can be undone from the message that follows.
- The restore result names how many windows were restored, not running or blocked, in the window's language.
- The installer carries the full licence texts of everything it ships (`THIRD_PARTY_LICENSES.txt`).
- Saving, restoring, shortcuts, auto-restore, launching apps and monitor handling work as in 0.1.0; layouts from 0.1.0 load unchanged.

## 0.1.0 (2026-11-02)

- First release: save window layouts across monitors, restore them with a shortcut or from the tray, monitor map, launch apps that aren't running, auto-restore when a monitor setup connects.
